# 2.5.0 release scope

This release converts the remaining research findings into first-party source intelligence without adding commercial runtime dependencies.

- Separate planned maintenance from active incidents.
- Preserve bounded vendor update timelines.
- Capture structured component state.
- Publish evidence tier and source confidence independently from service health.
- Track parser version, structural schema fingerprint, last success, consecutive failures, and last semantic change.
- Surface schema drift and source-failure streaks as source events, never vendor outages.
- Retain 200 bounded lifecycle records.
- Enable documented vendor-owned Statuspage JSON adapters for existing catalog providers.

The release remains static, unauthenticated, free, and fail-closed. The exact release head must pass provider validation, all deterministic tests, TypeScript checking, and the production Vite build before merge.
